## 2024-05-18 - Missing local node_modules
**Learning:** In certain sandbox environments, the `node_modules` directory might be corrupted or missing `.bin` executables, while internet access is also disabled, preventing `npm install`. This blocks standard workflows like `npm test` or `npm run build`.
**Action:** Always visually verify code modifications carefully since local testing through package managers may fail. Rely on core Javascript/React principles when making performance improvements and ensure changes are strictly syntactically correct since there is no compiler feedback loop.
