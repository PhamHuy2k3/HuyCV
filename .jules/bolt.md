## 2026-03-16 - Docusaurus Default Template Context Rendering Optimization
**Learning:** Docusaurus default homepage templates sometimes read from `useDocusaurusContext()` multiple times across parent and child components (e.g., `Home` and `HomepageHeader`). Since the site config is static, passing this down as a prop and wrapping with `React.memo()` avoids unnecessary duplicate context subscriptions and potential re-renders. The same principle applies to purely static feature lists (e.g., `HomepageFeatures` and `Feature`), which can be safely memoized to avoid redundant reconciliation when parent context state (like a theme toggle) changes.
**Action:** When working on generic React applications, especially those heavily relying on top-level static contexts, inspect the component tree for redundant context consumption. Prefer prop-drilling with `React.memo()` for statically configured, leaf-like child components.
