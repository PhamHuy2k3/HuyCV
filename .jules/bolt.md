## 2024-03-15 - [React.memo on Static Lists]
**Learning:** While `React.memo` is a powerful tool to prevent unnecessary re-renders in dynamic applications, applying it to components that receive completely static props (like the default Docusaurus `FeatureList`) within a stateless parent component yields almost zero measurable performance impact. It's essentially a micro-optimization in this specific context because the parent component rarely, if ever, re-renders during normal user interaction on the homepage.
**Action:** In the future, before applying `React.memo()`, verify that the parent component actually re-renders frequently enough to justify the overhead of the prop comparison, even if the props are static. Only apply it when a clear, measurable bottleneck is identified through profiling, rather than as a default pattern for all list items.
